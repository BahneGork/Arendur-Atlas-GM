# Blandede noter: spillerviden og GM-hemmeligheder

Noter i vaulten om noget, spillerne kender, som også rummer GM-materiale. Fundet automatisk 2026-10-16 (Claude) ud fra to slags tegn:

- **Spillerne kender emnet:** navnet står i deres egne noter (Player Vault, krøniken, cutscenes), `met: yes`, eller tag `#visited`/`#npcmet`.
- **GM-materiale:** sektioner som *Secrets*/*Clues*/*Stats*/*Motivation*, `#secret`, åbne spor `- [ ]`, stat blocks, eller formuleringer som *secretly*/*unofficially*/*in fact*.

Ingen af dem er delt i dag (ingen `dg-publish`, ingen `%%`), så intet slipper ud. Når en note skal deles: sæt `dg-publish: true` og læg GM-delene i `%% … %%`. Afslørede spor (`- [x]`, `#secretsrevealed`) kan typisk stå uden for `%%`.

Kolonnen *Afsløret* tæller `- [x]`-linjer og `#secretsrevealed`.
